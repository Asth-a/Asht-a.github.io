Automated Plant Health Monitoring & Pesticide Spraying System

FEB 2026 – MAY 2026
  • Developed an automated plant health monitoring system using an Arduino Uno, TCS34725 RGB sensor, DHT22, soil moisture sensor, and water-level sensor for continuous crop-condition assessment.
  • Implemented Green Leaf Index (GLI) analysis from RGB measurements and Vapor Pressure Deficit (VPD) calculation from temperature and humidity data to evaluate tomato plant stress.
  • Designed a four-level severity classification system that analyses sensor parameters and determines whether the plant is healthy or requires spraying.
  • Automated pesticide spraying through a relay-controlled 12V DC pump, with spray duration adjusted according to the detected severity level.
  • Integrated a cyclic monitoring mechanism that reads sensor data after a 10-second interval and continuously updates spraying decisions while preventing pump operation when the tank is empty.
